## 一、形狀與光影

| 項目 | 數值 | 用在哪 |
|---|---|---|
| 圓角 8 | `--ig-r-sm` | 焦點框、小元件 |
| 圓角 12 | `--ig-r-md` | Logo 方塊、圖示鈕、輸入框 |
| 圓角 14 | `--ig-r-input` | 搜尋框、FAQ 列 |
| **圓角 18** | `--ig-r-card` | **卡片（招牌）** |
| 圓角 22 | `--ig-r-lg` | 大卡、總覽格 |
| 圓角 32 | `--ig-r-xl` | 深色舞台 |
| 膠囊 | `--ig-r-pill` | 按鈕、膠囊、標籤、導覽列 |
| 邊框 | 1px `--ig-ink-hairline` | 所有白卡 |
| 陰影 xs | `0 1px 2px rgba(0,0,0,.04)` | Logo 方塊、白色按鈕、搜尋框 |
| 陰影 hover | `0 16px 32px -18px rgba(22,20,21,.22)` | 卡片 hover |
| 陰影 float | `0 14px 36px -16px rgba(0,0,0,.55)` | 浮動導覽列、toast |
| 陰影 stage | `0 40px 80px -44px rgba(0,0,0,.5)` ＋ 頂部 1px 白 6% 內光 | 深色舞台 |

**原則：分層靠線，不靠影。** 平常卡片幾乎零陰影，只有「浮在上面的東西」（導覽列、深色舞台、hover 中的卡片）才有影子，而且影子要「往下拉長、負擴散」——看起來輕，不髒。

## 二、元件規格

### 1. 按鈕 `.ig-btn`

| 變體 | 底 | 字 | 邊 | hover | 用途 |
|---|---|---|---|---|---|
| `--gold` | 金漸層 | `#2D2B2C` | 白 50% ＋ 1.4px 金光圈 | 加暖光、上浮 1px | 畫面唯一主動作 |
| `--ink` | `#2D2B2C` | 白 | — | 變 `#161415` | 第二重要動作 |
| `--ghost` | 白 | 墨 | 1px 8% | 邊框變 18% | 一般動作 |
| `--line` | 透明 | 白 | 白 18% | 底白 4% | 深色舞台上的次要動作 |

尺寸：`--sm` 高 32／14px／500；預設 高 44／15px／600；`--lg` 高 52／16px。按下去 `scale(.98)`。
圖示 16px 放文字右邊（→）表示前進，放左邊表示類別。

### 2. 導覽列 `.ig-nav`

- 深炭膠囊，**浮在內容上方**（sticky，離頂 16px），高 60，最寬 1280。
- 左：Logo 符號（金）＋名稱（白 700）；中：連結 14px 白 82%，選中＝白 10% 膠囊底；右：一顆 `--sm` 金色按鈕。
- 手機（< 860px）隱藏中間連結，改漢堡選單。

### 3. 篩選膠囊 `.ig-pill`

- 高 32、左右 14、14px／500。
- 未選：白底＋1px 8% 線＋65% 墨字；選中：`#161415` 底＋白字。
- 右邊帶計數 `.ig-pill__n`（12px、18% 墨；選中時白 50%）。「全部」永遠排第一。

### 4. 卡片 `.ig-card`

- 白底、1px 8% 線、18px、內距 24。
- 可點的卡加 `--link`：hover 上浮 2px＋邊框 18%＋hover 陰影。
- 卡片裡**不要再放卡片**；要分區就用 `--ig-card-alt` 淡底或一條髮絲線。

### 5. 工具卡 `.ig-tool`（目錄頁主角）

```
┌──────────────────────────────────────────┐
│ ┌──────┐  標題 17/600（一行，超過…）     ↗ │
│ │ Logo │  描述 14px 65% 墨，最多兩行…      │
│ │ 72px │                                   │
│ └──────┘  [標籤] [標籤]                     │
└──────────────────────────────────────────┘
  內距 16｜左右間距 16｜Logo 方塊 12px 圓角白底細框
```

- 描述固定保留兩行高度（`min-height: 3.1em`），整排卡片才會等高。
- 右上 ↗ 平常 18% 墨，hover 變 100% 並往右上移 2px——暗示「點下去會開新東西」。
- 網格：`.ig-grid`，最小欄寬 320px，間距 14px（桌面三欄、平板兩欄、手機一欄）。

### 6. 數據卡 `.ig-stat`

- 橫排：20px 圖示（45% 墨）＋等寬數字 22px＋13px 說明。
- 通常 4 張一排，放在 Hero 下方當「信任列」。

### 7. 便當格 `.ig-tile`

- 上方 180px 插圖區：淡底＋44px 髮絲格線＋中央一個漂浮圖示方塊。
- 下方文字區：h3 20px＋14px 描述。
- 一排 3 格時，**第一格用 `--dark`**，形成視覺起點。

### 8. 搜尋框 `.ig-search`

- 高 52、14px 圓角、白底、1px 8% 線。
- 左放大鏡 18px；右邊快捷鍵提示 `.ig-kbd`（`/` 或 `⌘K`）。
- focus：邊框變 `#FCD94A`＋3px 金色 45% 光圈。

### 9. 深色舞台 `.ig-stage`

- 深炭漸層、32px 圓角、內距 64（手機 28）、大陰影。
- 裡面的卡片用 `.ig-stage-card`（白 4% 底＋白 8% 線＋18px）。
- 常見三種用法：**訂閱／行動呼籲**（左文右表單）、**FAQ**（置中標題＋手風琴）、**重點故事**（左圖右文）。
- **一頁最多 2 塊**；兩塊之間至少隔 28px。

## 三、版面

### 1. 間距尺

`4 · 8 · 12 · 14 · 16 · 20 · 24 · 28 · 36 · 48 · 64 · 96`

- 卡片間距 **14**；卡片內距 **16**（工具卡）／**24**（一般卡）
- 區段上下 **96**（手機 64）；標題與內容 **28–36**
- 容器左右留白 **24**（手機 16）

### 2. 容器寬

| class | 寬 | 用途 |
|---|---|---|
| `.ig-container--narrow` | 720 | 文章、FAQ、表單 |
| `.ig-container` | 1100 | 一般頁面 |
| `.ig-container--wide` | 1280 | 目錄頁、平台、導覽列 |

### 3. 頁面骨架（目錄型網站）

```
[浮動深炭導覽列]
[Hero：左＝小帽子＋招牌大標＋導言＋金按鈕＋墨按鈕｜右＝漂浮圖示插圖]
[數據信任列：4 張數據卡]
[目錄：眉標＋h2 ｜ 右側「顯示 N 個」→ 搜尋框 → 篩選膠囊 → 工具卡網格]
[便當格：置中標題＋3 格（第一格深色）]
[對比：左文字｜右 ✗/✓ 卡片]
[深色舞台 1：行動呼籲]
[深色舞台 2：FAQ]
[頁尾：紙底＋上緣髮絲線，左品牌右連結欄]
```

### 4. 頁面骨架（平台／中控台）

```
[浮動深炭導覽列（或左側 240px 深炭側欄）]
[頁標 h1＋一行說明｜右：搜尋框＋金色「新增」按鈕]
[數據列：4 張數據卡（等寬數字）]
[篩選膠囊（附計數）]
[卡片網格（工具卡）或 表格卡（白卡內放表格，列高 52、髮絲分隔線、表頭 12px 眉標）]
[右下 toast：深炭膠囊]
```
長時間使用的平台可切 `data-theme="night"`。

### 5. 響應式

| 寬度 | 變化 |
|---|---|
| ≥ 1240 | 3 欄卡片、Hero 左右兩欄 |
| 900–1240 | 2 欄卡片、數據卡 2×2 |
| < 900 | Hero 疊成上下 |
| < 860 | 導覽列隱藏中間連結 |
| < 640 | 1 欄、容器留白 16、區段 64、Logo 方塊縮到 56 |

## 四、圖示

- 風格：**線條圖示**，24 格線、`stroke-width: 2`、圓角端點與轉角、不填色。推薦 Lucide（ISC 授權，可商用、可內嵌 SVG）。
- 尺寸：按鈕內 16、卡片與列表 18–20、Logo 方塊內 28–30、插圖方塊內 30。大於 24px 時線寬降到 1.75。
- 顏色：預設 45% 墨 → hover 100% 墨；深底白 70%；金色按鈕上用深炭。
- **禁止**：彩色 emoji 當 UI 圖示、同頁混用線條與實心圖示、線寬混用。
- 例外：第三方品牌 Logo 保留原色，但一定要裝進白底 12px 圓角方塊。

## 五、Logo

**這套風格的標誌**：深炭圓角方塊裡放一個金色書籤（＝「挑選、收藏、整理好」）。

幫其他品牌套用時的四條規則：
1. **符號極簡**：2–3 個幾何形狀以內，16px favicon 還認得出來。
2. **配色二選一**：金色符號＋深炭底，或墨色符號＋紙底。不做彩虹色、不做漸層立體（金色漸層除外）。
3. **字標**：英文可用 900 斜體；中文用 700–900 正體，不斜。
4. **擺放**：導覽列左側、頁尾左上、簡報封面左上；四周留白至少等於符號高度的一半。

## 六、插圖與圖片

這套風格的插圖語言是**「墨線角色 × 漂浮圖示方塊 × 金色細線」**：

| 元素 | 怎麼畫 |
|---|---|
| 墨線角色 | 自家原創吉祥物（例如南瓜角色），黑色手繪輪廓 2–3px、白色填色、略帶塗鴉筆觸、不上彩色 |
| 漂浮圖示方塊 | 圓角方塊（約 20px 圓角）、微傾 ±5–12°、柔和立體（上緣白色高光＋下方淡影）、內放單色線條圖示；顏色從 白／金／淡藍／淡粉／深炭 挑 |
| 金色細線 | 從中心向外放射、兩端淡出，像「連接」 |
| 格線底 | 44px 髮絲格線，放在插圖區底 |

- 純 CSS 做法見 `assets/demo-directory.html` 的 `.hub`（漂浮方塊＋放射線）。
- 需要生成圖時，用 `references/AI咒語.md` 的生圖模板。**不要模仿任何現成品牌的吉祥物。**
- 照片：少用；要用就放進 18px 圓角容器、稍微降飽和，避免搶走金色焦點。

## 七、動態

| Token | 值 | 用途 |
|---|---|---|
| `--ig-fast` | 120ms | 變色（hover 字、邊框） |
| `--ig-base` | 200ms | 浮起、陰影、按鈕 |
| `--ig-slow` | 320ms | toast、面板淡入 |
| `--ig-reveal` | 620ms | 捲動進場（`.ig-reveal` → `.is-in`） |
| `--ig-ease` | `cubic-bezier(.4,0,.2,1)` | 預設 |
| `--ig-ease-emph` | `cubic-bezier(.2,0,0,1)` | 出現、展開 |
| `--ig-ease-reveal` | `cubic-bezier(.22,1,.36,1)` | 進場 |

- 只做：上浮 1–2px、變色、淡入、往上滑 14px。
- 不做：彈跳、旋轉、縮放超過 2%、跑馬燈、視差捲動。
- 插圖方塊可以 6 秒慢慢上下浮動 10px。
- 使用者開「減少動態」時，套件自動把所有時長改成 1ms。
