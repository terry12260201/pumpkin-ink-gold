# 元件與版面｜南瓜墨金美學 1.2

先把資訊排整齊，再加裝飾。目錄規格來自實測校準；品牌與工作區屬同語言的延伸。

## 1. 目錄骨架

```text
浮動深炭導覽
       置中短標題
       一句說明
       可選快捷入口

瀏覽內容                         搜尋
分類膠囊  分類膠囊  分類膠囊

[識別圖＋文字] [識別圖＋文字] [識別圖＋文字]
[識別圖＋文字] [識別圖＋文字] [識別圖＋文字]

簡單頁尾／補充說明
```

`body class="ig ig-directory"` 啟用目錄模式。容器1248px含左右24px內距，**內容淨寬1200px**；1440px畫面時左右各留120px。不要把外容器與內容寬混為一談。

## 2. 元件尺寸

| 元件 | 規格 | 細節 |
|---|---|---|
| 導覽 | 高60、寬最多1200、頂距24 | 深炭膠囊；手機頂距12、左右12 |
| 導覽項目 | 14px、圓膠囊選中底 | 選中用淡白底，主要動作才用金色 |
| 分類 | 高32、左右約14、項目距8 | 墨底白字代表選中；帶計數，使用aria-pressed |
| 卡片 | 圓角18、邊1px墨8%、內距16 | 平時無厚陰影 |
| 圖文間距 | 16 | 圖片不貼著標題 |
| 識別圖 | 76×76、圓角12 | 手機64；圖形主體約40，保持比例 |
| 卡片間距 | 12 | 橫直一致 |
| 搜尋 | 約40–52高、圓角14或膠囊 | 40適合目錄工具列，52適合獨立主搜尋 |
| 一般按鈕 | 高44、膠囊 | 緊湊32、大按鈕52；依觸控需求調整 |
| 工作區輸入框 | 高44、圓角12 | 永遠有名稱，placeholder不是標籤的替代品 |

### 白卡裡放什麼

識別圖、名稱、最多兩行摘要、少量分類或狀態。長中文名稱可兩行。卡片高度隨中文內容增加，不強制鎖死原站約133.5px的高度。

整張卡如果導向同一個地方，使用一個連結。若另有收藏按鈕，使用獨立按鈕，避免把按鈕塞進連結。

### Logo 和 Icon

品牌Logo用現成資產，保留原色、比例與安全留白。自有主題圖使用Phosphor雙色圖標，圖形50px＋底座76px，手機整組64px；操作圖示16–20px、約2px線寬、圓角端點、單色。

向量圖示是辨識入口，不必把每個圖都畫成金色。照片是內容證據或主角時才放大，工具索引優先小識別圖。

## 3. 響應式

| 寬度 | 排法 |
|---|---|
| ≥1024px | 三欄 |
| 641–1023px | 兩欄 |
| ≤640px | 一欄、頁面左右16px |

CSS使用 `repeat(3, minmax(0, 1fr))` 避免長字撐破欄位。分類可換行或收進「更多」；若隱藏導覽文字，保留可理解的圖示名稱及入口。

首屏盡快露出第一排內容。不要讓大插圖、統計卡、分類列一起把結果推到很遠。

## 4. 互動

| 狀態 | 回應 |
|---|---|
| hover | 卡片上移1px，邊線加深，約200ms |
| focus-visible | 清楚的深色外框＋金色輔助圈 |
| active | 回到原位或輕微壓下 |
| 選中分類 | 墨底白字，同時更新可讀狀態 |
| 沒有結果 | 說明沒有找到，提供清除或改搜尋方式 |
| 載入 | 真有等待工作時顯示進度，不用假倒數 |
| 錯誤／完成 | 說明結果和可做的下一步 |

減少動態設定下取消位移；對話框支援Esc與焦點返回。純連結不需要假造loading或success狀態。

## 5. 按用途換骨架

**品牌頁**：主張 → 產品或案例 → 說明 → 行動。大插畫、粗細標題、深色舞台可用，不是必填欄位。

**工作區**：名稱與狀態 → 輸入／操作 → 結果。常用功能優先；資料表需要比較時，直接用表格，不強迫全部變卡片。

**深色舞台**：用於需要停下來閱讀的重點段落，圓角32、內距約28–64；由內容決定是否使用，不要求每頁都有。

## 6. 常見走樣

| 走樣 | 修正 |
|---|---|
| 只換成黑金，排版還是巨大宣傳頁 | 改用短導讀與三欄橫卡 |
| Logo大小相同，看起來卻忽大忽小 | 校準圖形主體與留白，不只校準外框 |
| 所有按鈕都金色 | 找出本區最重要的動作，其他降為白底或墨底 |
| 中文很擠 | 字距回0、增加行高、放寬到兩行 |
| 每張卡都厚陰影 | 回到1px淡線，hover才加陰影 |
| 次要字太淡 | 提高文字對比；裝飾淡，必要內容清楚 |

## 互動背景與主題

CSS負責顏色，`ink-gold-ui.js`負責點陣與主題切換。空白處吸向游標，按鈕旁吸向圓角輪廓；離開復位。不要用背景位置平移或單純放大取代。切換按鈕使用 `data-ig-theme-toggle`，腳本放在body結尾；既有主題系統加 `data-theme="external"`，並維持body的day／night屬性。

新增圖示時沿用 [來源清單](../assets/icons/SOURCES.md) 的Duotone家族，避免不同筆畫粗細混用。白底原廠Logo與柔色主題圖可並存，各自保留比例。
