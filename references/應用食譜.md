# 🍳 應用食譜｜南瓜墨金美學

> 同一套 DNA，換到不同地方怎麼做。每道食譜都是「骨架＋重點＋小心」三段。

---

## 1. 🌐 官網／產品介紹頁（Landing Page）

**骨架**：浮動導覽列 → Hero（招牌大標＋金按鈕＋插圖）→ 數據信任列 → 功能便當格 → 對比 ✗/✓ → 見證卡片 → 深色舞台行動呼籲 → FAQ 深色舞台 → 頁尾

**重點**
- 整頁只有 Hero 的主按鈕與最後行動呼籲是金色（兩處是同一個動作）。
- 區段標題上方放 `.ig-kicker` 小帽子，讓每一段都有「標籤感」。
- 見證卡：白卡、頭像 40px 圓形、名字 14/600、身分 13px 45% 墨、標題 16/600、內文 14px。

**小心**：不要每段都放插圖；插圖只在 Hero 和便當格。

## 2. 🗂️ 目錄型網站（工具庫、課程庫、資源庫、作品集）

**骨架**：`assets/demo-directory.html` 直接改內容。
**重點**
- 資料寫成陣列，卡片用 JS 生成；搜尋＋膠囊篩選同時生效；右上顯示「顯示 N / 總數」。
- 每張卡：Logo 方塊、標題、兩行描述、1–2 個標籤。**描述一律兩行**，太長就截斷。
- 分類不超過 8 個膠囊；更多就加「更多 ▾」。

**小心**：卡片數量一多，Logo 方塊的顏色會變吵——自家圖示一律用單色線條，只有第三方品牌 Logo 保留原色。

## 3. 🛠️ 網頁小工具（單檔 HTML）

**骨架**：窄容器（720）→ 頁標 h1＋一行說明 → 白卡輸入區 → 金色「執行」按鈕 → 結果白卡 → toast 回饋
**重點**
- 南瓜鐵則：**單一 HTML、file:// 雙擊直開、零外部資源** → 不載 Google Fonts，大標反差改 600 對 200。
- 輸入區用 `.ig-input`／`.ig-search`；結果區頂端放 `.ig-eyebrow`「RESULT · 結果」。
- 複製、下載等小動作用 `.ig-btn--ghost --sm`，只有「執行」是金色。

**小心**：交付前用 headless Chrome 對 `file://` 截圖驗證。

## 4. 🎛️ 平台／中控台／儀表板

**骨架**：見 `元件與版面.md` 的「頁面骨架（平台）」。
**重點**
- 入口總覽頁＝**卡片目錄**（每個功能一張工具卡，有 Logo 方塊、名稱、一句話、狀態標籤），不要做成密密麻麻的表格牆。
- 狀態用 `.ig-live` 金點（進行中）、`.ig-tag`（分類）、`.ig-badge`（新）。
- 數據卡的數字用等寬字；趨勢圖用金色單線＋淡金面積。
- 長時間使用 → 提供 `data-theme="night"` 切換（右上圖示鈕）。
- 側欄版：左側 240px 深炭側欄，選中項＝白 10% 膠囊＋左側 3px 金條。

**小心**：中控台很容易「每個區塊都想要重點」→ 金色仍然一畫面一個（通常是「新增」）。

## 5. 🎞️ 簡報

### HTML 簡報
直接複製 `assets/demo-slides.html`：1920×1080 畫布自動縮放、←→ 翻頁、網址 `?p=3` 跳頁。已有五種版型：封面／三重點卡片／大數字／前後對比／深色收尾。

### Google 簡報、PowerPoint、Keynote（手動設定）

| 項目 | 設定 |
|---|---|
| 投影片大小 | 16:9 |
| 背景 | `#F5F5F5`（可放一張點格 PNG 當背景圖）；收尾頁 `#2D2B2C` |
| 標題字 | Roboto／Noto Sans TC，封面 900＋300 兩行，內頁標題 700 |
| 內文 | 同上 400，顏色 `#161415` 的 65%（或直接用 `#6E6C6D`） |
| 眉標／頁碼 | Roboto Mono，全大寫，字距加寬，顏色 `#8F8D8E` |
| 卡片 | 白色圓角矩形（圓角約 8%）、邊框 1pt `#EBEBEB`、無陰影 |
| 重點 | 一頁只有一個金色 `#FDC302` 元素（按鈕狀膠囊、重點數字下的線、或螢光筆底 `#FDE68A`） |
| 頁尾 | 左：品牌名等寬字；右：`03 / 12` 等寬字 |

**版型建議**：封面（左上 Logo＋眉標、左下大標）→ 目錄（編號卡片）→ 內容（一頁一件事）→ 數據（等寬大數字＋金色頂線）→ 對比（白卡 vs 深炭卡）→ 收尾（深炭底＋金色膠囊按鈕）。

**小心**：PowerPoint 沒裝 Roboto／Noto Sans TC 時會掉字，檔案要給別人前先嵌入字型或轉 PDF。

## 6. 📄 文件、報告、提案書（Google 文件／Notion／Obsidian／Word）

| 元素 | 做法 |
|---|---|
| 封面 | 紙底、左上小 Logo、眉標 `PROPOSAL · 2026`、大標粗細兩行、下方一條 2px 金線 |
| 標題 | H1 28–32pt 700；H2 20pt 700；H3 14pt 700 |
| 內文 | 11pt、行距 1.6、顏色深灰 `#4A4849` |
| 重點框 | 淡底 `#FAFAFA`＋左側 3px 金條（Notion 用 callout 灰底＋🟨） |
| 表格 | 表頭灰底 `#F5F5F5`、字 9pt 大寫等寬；列線 `#EBEBEB`；不用直線 |
| 數字 | 等寬字（Roboto Mono）對齊 |
| 頁首頁尾 | 等寬 8pt 灰字：左品牌、右頁碼 |

**小心**：標書、公文類若規定標楷體，以規定為準，墨金只用在封面與圖表。

## 7. 📱 社群圖卡、YouTube 縮圖、Threads／IG 輪播

- **尺寸**：IG 1080×1350、輪播 1080×1080、YouTube 1280×720。
- **版型 A（知識卡）**：紙點格底 → 左上眉標 `TIP 01` → 粗黑大字 2 行（第二行細體）→ 一個關鍵字用螢光筆底 → 右下小 Logo。
- **版型 B（封面／縮圖）**：深炭底 → 白色 900 大字 → 一個金色膠囊標籤（例如「3 分鐘學會」）→ 漂浮圖示方塊插圖。
- **輪播**：第 1 張用 B、中間用 A（右上角頁碼 `02/07` 等寬字）、最後一張深炭底＋金色行動呼籲。

**小心**：手機上字要大——知識卡主標 ≥ 72px（以 1080 寬計）。

## 8. ✉️ 電子報（Email）

- Email 不支援外部字體與大部分 CSS：字體寫 `Roboto, "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", Arial, sans-serif`。
- 結構：600px 寬、`#F5F5F5` 外框、白色主體卡（圓角 18、內距 32）→ 眉標 → 標題 → 內文 → 金色按鈕（用表格做，`background:#FDC302; color:#2D2B2C; border-radius:999px`）→ 深炭頁尾區塊。
- 點格背景 Email 做不到，省略即可。

## 9. 🎟️ 活動頁、報名頁

- Hero 放日期地點：眉標 `EVENT · 2026.10.24 · TAIPEI`（等寬）。
- 議程用時間軸：左側等寬時間、中間 8px 圓點（進行中的用金色＋微光）、右側白卡。
- 報名表單放深色舞台裡，送出按鈕金色。

## 10. 🪪 識別小物（名片、識別證、簡報模板封面、貼紙）

- 名片正面：紙白底、左上 Logo、名字 Noto Sans TC 900、職稱等寬字 45% 墨。
- 名片背面：深炭底、置中金色符號。
- 識別證：上半深炭（Logo＋活動名）、下半白（名字 900 大字＋單位等寬字）。

## 11. 🥽 XR／VR／遊戲 UI（UE5 UMG、Unity UI）

這套風格很適合頭戴裝置選單：深炭面板對比強、金色焦點一眼找到。

| 項目 | 做法 |
|---|---|
| 主題 | 用**夜間版**：面板 `#242223` 約 92% 不透明，外框白 8% |
| 選中／可互動焦點 | 金色 `#FDC302` 外框光圈＋卡片上浮（Z 方向前推 1–2cm） |
| 字體 | Roboto（UE 引擎預設字就是 Roboto）＋ Noto Sans TC 匯入為 Font Face |
| 字級 | 世界空間 UI：1 公尺距離時內文 ≥ 1.2cm 高、標題 ≥ 2cm |
| 線條 | 1px 髮絲線在頭顯上會閃爍 → 改 2–3px、透明度提高到 15–20% |
| 圓角 | 用 9-slice（Box）材質做 18px 圓角面板 |
| 色碼 | UE Color Picker 請貼到「Hex sRGB」欄，不是 Linear |
| 動態 | 懸停時 150ms 放大 1.02＋金框淡入；不要大幅彈跳（會暈） |

## 12. 📊 圖表與資料視覺

- 單系列：金色線 2.5px、資料點 6px 白心金框、面積金色 30%→0%。
- 多系列：依序 `#FDC302 #4DA770 #D97858 #4D6BFE #615CED`；最重要的系列放第一個（金色）。
- 格線：水平髮絲線（8% 墨），不畫垂直格線。
- 座標軸字：12px、45% 墨；年份、數值用等寬字。
- 最新值：在最後一個點旁加白底小膠囊標數字。
- 資料來源：圖下方 12px 45% 墨，「來源」兩字加底線。
