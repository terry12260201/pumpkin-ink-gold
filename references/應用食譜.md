# 應用方式｜南瓜墨金美學 1.1

同一盒文具，可以寫筆記、做海報，也可以做簡報。保留紙、墨、金與清楚層級；尺寸和骨架跟著用途變。

## 網站與平台

| 用途 | 建議骨架 | 保留哪些DNA |
|---|---|---|
| 工具／資源目錄 | 短導讀 → 搜尋分類 → 三欄橫卡 | 1200淨寬、76識別圖、12間距 |
| 知識／學習平台 | 主題分類 → 文章卡 → 完整內容 | 摘要先講用途，閱讀時間做次要資訊 |

| 儀表板 | 當前狀態 → 常用操作 → 資料 | 可比對資料用表格，功能入口用卡片 |
| 網頁工具 | 輸入 → 執行 → 結果 | 一個主要動作，清楚顯示等待、錯誤與完成 |
| 活動／報名頁 | 日期地點 → 議程 → 報名 | 金色指向報名，時間與條件寫清楚 |

## 簡報

### 版型

1. 封面：一句主張，少量品牌標誌。
2. 說明：一頁一件事，最多幾個平行重點。
3. 數據：圖表或數字當主角，附來源。
4. 比較：同欄位左右對照，差異用金色點出。
5. 收尾：把決策或下一步寫清楚。

16:9是建議起點。標題可從32–44pt、內文20–28pt開始，依展示距離調整；這些是簡報建議，不是網頁實測值。背景紙灰、內容墨色、金色凸顯關鍵。表格或圖表密集時省略點格。

`assets/demo-slides.html` 是五頁HTML範例，支援左右鍵與按鈕。PowerPoint／Keynote／Google Slides需另外製作原生文字、形狀與圖表；不要把整頁截圖當作可編輯投影片。

## 文件與操作手冊

A4文件可從內文11–12pt、標題20–28pt、行距1.5–1.7開始。先以章節、步驟、對照表組織；金色用在關鍵提示。列印時可省略底紋，表格欄位和來源要保留。

指定格式或字體優先於美術規範。灰字與淡線需測試黑白列印，不能只看螢幕。

## 社群、電子報與識別物

| 媒介 | 調整方式 |
|---|---|
| 社群圖卡 | 一張一個重點；大字、短句、少量標記；尺寸以當次平台需求為準 |
| 影片縮圖 | 一個主題與識別圖；縮小後仍認得出來 |
| 電子報 | 單欄、系統字體備援、實際郵件客戶端測試；不依賴複雜背景與動畫 |
| 名片／識別證 | 名字和必要資訊優先；紙灰與深炭可分正反面 |
| 展示／觸控介面 | 依觀看距離放大文字與觸控區域；測試現場光線與操作距離 |

## 圖表

主要系列用金色，其餘使用輔助色，搭配標籤、符號或線型。必要的刻度與資料來源使用可讀灰。格線淡，數據清楚；有多組同等重要資料時，不必硬指定其中一組為金色主角。

## XR／VR延伸

可延伸的是墨色面板、金色焦點與一致的圖示語言。世界空間字級、材質、透明度、互動距離及立體位移都需依頭顯、視距、背景與操作方式實測；網頁18px圓角或1px線條不能直接當成頭顯規格。

## 插圖與素材

工具目錄優先清楚的小識別圖。品牌故事可搭配原創插畫：墨線、簡潔輪廓、少量金色或輔助色，主題必須與內容有關。照片要有來源與用途。圖示優先向量，保留可編輯性。

把需求交給AI時，使用 [AI咒語](AI咒語.md)，再寫清楚這次要做的媒介、內容和輸出格式。
