# 互動點格背景 ＋ 公司品牌（墨金 v1.2 增補，2026-09-19 定案）

> 這兩樣是在 Pumpkin Notes（團隊影片筆記）做到定位的，南瓜點名「一定要保留、不能改壞」。之後任何墨金風格的網站／工具直接沿用，不要重做。

## 1. 互動點格背景（南瓜最喜歡的「表演」）
不是 CSS 背景圖，是一張**全螢幕固定的 canvas**，滑鼠靠近的點會亮起、變大。
- 位置：`<canvas id="pn-dots" aria-hidden="true"></canvas>` 放 `<body>` 第一個；CSS `#pn-dots{position:fixed;inset:0;width:100%;height:100%;pointer-events:none;z-index:-1}`；**body 要加 `position:relative;isolation:isolate;background-image:none`**（否則 canvas 會被 body 底色蓋掉，或跟 kit 的 CSS 點格疊成兩層）。
- 參數（定案，不要調）：點距 24px、半徑 1px、底色墨 `22,20,21` 透明度 0.10（夜間白 0.06）；游標半徑 140px 內：透明度線性升到 0.45、半徑升到 1.8px；`requestAnimationFrame` 節流；`prefers-reduced-motion` 時靜態；**不用金色**（守金色紀律）。
- 程式（2026-09-20 合併後）：本 skill 的 `references/ink-gold-ui.js` 已內建這個行為，**預設就是它**（模式名 `glow`），頁尾 `<script src="references/ink-gold-ui.js"></script>` 即可；原始出處是 Pumpkin Notes `data/store.js` 的 `PN.dots`，兩邊參數一致。另有選用的「磁吸」模式（點會往游標靠、沿按鈕輪廓收攏），要用才寫 `<body data-dots="magnetic">`；沒指定一律是定案版。
- 日夜切換：`body[data-theme="night"]`，存 `localStorage.pnTheme`，預設跟系統；點格顏色跟著換。
