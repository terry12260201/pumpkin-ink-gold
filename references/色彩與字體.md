# 色彩與字體｜南瓜墨金美學 1.2

把顏色當成工作分配：紙負責承載，墨負責閱讀，金負責指路。
本文件的顏色對應 `ink-gold.css`；原站觀察與改編差異見 [design.md](../design.md)。

## 1. 共通色票

| 角色 | Token | 數值 | 用途 |
|---|---|---|---|
| 紙 | `--ig-paper` | `#F5F5F5` | 頁面底 |
| 卡 | `--ig-card` | `#FFFFFF` | 卡片與輸入區 |
| 墨 | `--ig-ink` | `#161415` | 標題、主要內容 |
| 摘要 | `--ig-ink-muted` | 墨65% | 一般說明 |
| 可讀小字 | `--ig-label-readable` | 墨64% | 閱讀時間、分類、必要提示 |
| 裝飾次要墨 | `--ig-ink-soft` | 墨45% | 非必要輔助資訊；不可直接當對比合格保證 |
| 髮絲線 | `--ig-ink-hairline` | 墨8% | 卡片邊界 |
| hover線 | `--ig-ink-faint` | 墨18% | 滑過或選單邊界 |
| 炭 | `--ig-night` | `#2D2B2C` | 深色導覽 |
| 深炭 | `--ig-night-deep` | `#242223` | 深色面板 |
| 金 | `--ig-gold` | `#FDC302` | 主要動作 |
| 淺金 | `--ig-gold-light` | `#FFD83A` | 金按鈕漸層上緣 |
| 金上文字 | `--ig-on-gold` | `#2D2B2C` | 金底上的深色字 |
| 淺底金字 | `--ig-gold-deep` | `#8A6400` | 更容易閱讀的金色小字；1.1改編值 |

深底主要字用白色，摘要約68%白。細線、淡點與必要文字的對比要求不同；不要只靠透明度數字判斷可讀性。

## 2. 點格怎麼放

桌面點陣間距16px、半徑0.6px、淺色暖黑30%；夜間白18%。游標靠近時位置會內縮，移到按鈕則靠向輪廓。≤768px與減少動態時保留靜態；完整互動參數見 [design.md](../design.md)。

表格、文件列印與資料密集區可省略點格。底紋不能穿透白卡。

## 3. 字體分工

```css
--ig-font-sans: "Roboto", "Noto Sans TC", "PingFang TC",
  "Microsoft JhengHei", -apple-system, sans-serif;
--ig-font-mono: "Roboto Mono", "SF Mono", Menlo, Consolas,
  "Noto Sans TC", "PingFang TC", monospace;
```

Roboto主要承擔英文，Noto Sans TC承擔中文；等寬字只放編號、程式碼或需要對齊的數字。不要把整段中文摘要換成等寬字。

線上可載入網頁字體；離線提供本機備援或合法可散布的字型檔。備援字體的粗細與字寬不同，須看實際版面，不保證逐像素一致。

## 4. 網頁字級階梯

| 元素 | 桌面 | 手機 | 字重／行高 |
|---|---:|---:|---|
| 目錄主標 | 36–40px | 30px | 600／1.3 |
| 區段標題 | 22px | 21–22px | 700／1.5 |
| 卡片標題 | 17px | 16–17px | 600／1.45–1.5 |
| 主導讀 | 16px | 14–16px | 400／1.75 |
| 卡片摘要 | 14px | 13–14px | 400／1.6–1.75 |
| 分類與狀態 | 12–14px | 12–13px | 400–500／1.5 |
| 品牌展示大標 | 可用62px | 約38px起 | 900搭配300；依內容選用 |

操作工具的頁標可縮至24–32px，讓工作區先被看見。簡報與文件用各自媒介的字級，不直接複製CSS的px數字。

## 5. 中文排版

- 中文用正體、字距0；強調用字重、位置或淡底。
- 長中文卡片標題保留兩行，摘要最多兩行；全文入口仍可達。
- 同一排卡片預留相同標題／摘要高度；短文不必硬湊字數。
- 按鈕文字維持一行；太長先改文案，再調寬度。
- 小字維持可讀，重要操作標籤通常至少12px。用截圖實看，而非只檢查CSS數字。

## 6. 輔助色與夜間版

淡黃 `#FDE68A`、粉 `#FDA4AF`、藍 `#BAE6FD` 可做少量標記。圖表可使用套件chart tokens，搭配文字或線型辨識，不只依賴顏色。

夜間版是延伸：紙 `#1A1819`、卡 `#242223`、主要字 `#F7F7F7`。目錄預設仍以淺色作視覺基準；切換主題不改資訊順序。
