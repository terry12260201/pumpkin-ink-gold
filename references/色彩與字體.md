# 🎨 色彩與字體｜南瓜墨金美學

> 所有數值都已寫進 `ink-gold.css` 的 `--ig-*` 變數。**做東西時用變數，不要手打色碼**，之後要改色只改一處。

---

## 一、色彩系統

### 1. 四大色族

| 色族 | 角色 | 比例（一個畫面大約） |
|---|---|---|
| 紙 Paper | 舞台底、卡片 | 70% |
| 墨 Ink | 文字、選中狀態、線條 | 20% |
| 炭 Night | 導覽列、深色舞台 | 8% |
| 金 Gold | 唯一的重點 | 2% |

> 記法：**紙是桌面，墨是筆，炭是聚光燈下的舞台，金是螢光筆最重要那一劃。**

### 2. 紙 Paper

| Token | 色碼 | 用途 |
|---|---|---|
| `--ig-paper` | `#F5F5F5` | 頁面底色 |
| `--ig-dot` | `rgba(22,20,21,.10)` | 點格（1px 圓點、16px 間距；簡報 1920 畫布用 28px） |
| `--ig-card` | `#FFFFFF` | 卡片、輸入框、白色按鈕 |
| `--ig-card-alt` | `#FAFAFA` | 卡片內的次要區、插圖區底 |

### 3. 墨 Ink（一個顏色＋透明度階梯）

| Token | 值 | 用途 |
|---|---|---|
| `--ig-ink` | `#161415`（100%） | 大標、卡片標題、選中膠囊底、重要數字 |
| `--ig-ink-muted` | 65% | 內文、卡片描述、副標 |
| `--ig-ink-soft` | 45% | 標籤字、時間、計數、眉標、未啟用圖示 |
| `--ig-ink-faint` | 18% | hover 時的卡片邊框、膠囊計數、停用 |
| `--ig-ink-hairline` | 8% | 卡片邊框、分隔線、格線 |
| `--ig-ink-wash` | 4% | 小標籤底、進度條軌道 |

為什麼用透明度不用灰色：同一支墨水寫出來的字，濃淡不同但色相一致，整頁會很「乾淨」；換成五種灰就會髒。

`#161415` 不是純黑：帶一點點暖紅，比 `#000` 柔和、印刷感更好。

### 4. 炭 Night（深色舞台）

| Token | 值 | 用途 |
|---|---|---|
| `--ig-night` | `#2D2B2C` | 浮動導覽列、墨色按鈕、深色舞台底 |
| `--ig-night-deep` | `#242223` | 深色卡片、深色便當格 |
| `--ig-night-hover` | `#292728` | 深色元件 hover |
| `--ig-night-gradient` | `135deg #333233 → #242223 60%` | 深色舞台大區塊（左上微亮） |
| `--ig-on-night` | `#FFFFFF` | 深底標題 |
| `--ig-on-night-muted` | 白 68% | 深底內文 |
| `--ig-on-night-soft` | 白 45% | 深底眉標、說明小字 |
| `--ig-night-line` | 白 8% | 深底卡片邊框 |
| `--ig-night-wash` | 白 4% | 深底卡片、輸入框底 |

### 5. 金 Gold

| Token | 色碼 | 用途 |
|---|---|---|
| `--ig-gold` | `#FDC302` | 金色按鈕外框光圈、進度條、勾勾、圖表第一系列 |
| `--ig-gold-light` | `#FFD83A` | 金色漸層上端 |
| `--ig-gold-gradient` | 下 `#FDC302` → 上 `#FFD83A` | 金色按鈕、金色圖示鈕 |
| `--ig-gold-soft` | `#FCD94A` | 輸入框 focus 光圈、深底上的 hover 文字 |
| `--ig-gold-deep` | `#B88800` | **淺底上的金色文字**（百分比符號、編號、連結 hover） |
| `--ig-gold-wash` | `#FEF3C7` | 極淡金底（提示框，少用） |
| `--ig-on-gold` | `#2D2B2C` | 金色上面的文字 |

金色三條紀律：
1. **一個畫面只有一個金色主角**（通常是主按鈕）。第二個重要動作用墨色按鈕。
2. 金底配**深炭字**，不配白字（白字在金底上讀不清）。
3. 白底上**不要用 `#FDC302` 當文字色**，要金色字就用 `#B88800`。

金色按鈕的光：平常 `0 0 0 1.4px #FDC302` 細光圈；hover 加一層 `0 12px 26px -10px rgba(253,195,2,.55)` 暖光。

### 6. 點綴與訊號（少量）

| Token | 色碼 | 用途 |
|---|---|---|
| `--ig-mark-yellow` | `#FDE68A` | 螢光筆重點（中文強調首選） |
| `--ig-mark-pink` | `#FDA4AF` | 插圖方塊、第二種螢光筆 |
| `--ig-mark-blue` | `#BAE6FD` | 插圖方塊、第三種螢光筆 |
| `--ig-success` | `#059669` | ✓、成功狀態 |
| `--ig-danger` | `#DC2626` | ✗、刪除、錯誤 |

### 7. 圖表色（依序使用）

`#FDC302`（金）→ `#4DA770`（綠）→ `#D97858`（陶土）→ `#4D6BFE`（藍）→ `#615CED`（紫）

- 只有一條線／一組資料：用金色，面積填色用金色 30% → 0% 由上往下漸層。
- 格線用 `--ig-ink-hairline`，座標字用 `--ig-ink-soft` 12px。
- 重點數值用白底小膠囊標在資料點旁邊。

### 8. 夜間版（`data-theme="night"`）

給中控台、長時間盯螢幕、XR 介面用。紙變 `#1A1819`、卡變 `#242223`、墨變 `#F7F7F7`（透明度階梯照舊），金色不變。點格改成白 6%。

## 二、字體系統

### 1. 三支字體

| 角色 | 英數 | 中文 | 什麼時候用 |
|---|---|---|---|
| 主字體 | Roboto | 思源黑體 Noto Sans TC（Mac 退蘋方、Windows 退微軟正黑） | 標題、內文、按鈕 |
| 等寬字 | Roboto Mono | 同上 | 眉標、數據、日期、代碼、主題晶片、頁碼 |
| — | — | — | 不用第三支字體；不用襯線體；不用圓體 |

等寬字是這套風格的「系統感」來源：數字對齊、眉標像終端機標籤，讓頁面有「被精準整理過」的味道。

| 卡片標題 | `.ig-tool__title` | 17 | 17 | 600 | 1.4 | 0 |
| 導言 | `.ig-lead` | 17 | 17 | 400 | 1.75 | 0 |
| 內文 | `.ig-body` | 16 | 16 | 400 | 1.75 | 0 |
| 描述 | `.ig-small` | 14 | 14 | 400 | 1.6 | 0 |

### 3. 招牌大標怎麼寫

英文頁：
```html
<h1 class="ig-display">
  <span class="ig-display__strong"><em>Clear tools,</em></span>
  <span class="ig-display__light">calm workdays</span>
</h1>
```

中文頁（**粗黑正體＋細體**；英文字詞才斜）：
```html
<h1 class="ig-display">
  <span class="ig-display__strong">每天用得到的</span>
  <span class="ig-display__light"><em style="font-style:italic;font-weight:900">AI</em> 工具，都在這</span>
</h1>
```

### 4. 中文排版規則（最重要）

| 規則 | 為什麼 | 怎麼做 |
|---|---|---|
| 中文不斜體 | 中文字型沒有斜體設計，瀏覽器硬拗很醜 | 強調用 `.ig-mark` 螢光筆底，或加粗 |
| 中文不負字距 | 中文方塊字擠在一起會糊 | `<html lang="zh-Hant">`，套件自動歸零 |
| 行高加大 | 中文筆畫密，需要更多呼吸 | 內文 1.75、大標 1.2 |
| 最小 12px | 11px 中文在一般螢幕上會糊掉 | 標籤、計數都 ≥ 12px |
| 眉標中英混排 | 中文不能「大寫」，全中文眉標會沒有系統感 | `01 · TOOLKIT · 工具包` 這種格式 |
| 全形標點 | 台灣用語習慣 | ，。「」：；（）—— |
| 中英文間留空格 | 可讀性 | `AI 工具`、`3 步` |

### 5. 字體怎麼載入

**上線網頁**（有網路）：
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,300;0,400;0,500;0,600;0,700;0,900;1,900&family=Roboto+Mono:wght@400;500&family=Noto+Sans+TC:wght@300;400;500;700;900&display=swap" rel="stylesheet">
```

**離線單檔小工具**（file:// 雙擊直開、零外部資源）：不要載上面那行，套件的字體堆疊會自動退到系統字。注意：

| 系統 | 中文會用 | 最粗 | 大標反差改成 |
|---|---|---|---|
| macOS | 蘋方 PingFang TC | 600 | 600 對 200 |
| Windows | 微軟正黑體 | 700 | 700 對 300（正黑只有 300／400／700） |

**簡報／文件軟體**：Google 簡報與 Google 文件內建 Roboto、Roboto Mono、Noto Sans TC，直接選；PowerPoint／Keynote 要先到 Google Fonts 免費下載安裝這三支，沒裝就用「微軟正黑體／蘋方」代替。
